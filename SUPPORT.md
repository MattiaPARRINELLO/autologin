# Support

CheckMate est un projet benevole. Le support passe uniquement par les canaux
publics ci-dessous : il n'y a ni adresse e-mail dediee, ni support prive.

## Avant de demander de l'aide

1. Lire le [guide utilisateur](watcher/docs/guide-utilisateur.md) :
   installation, configuration, mise a jour.
2. Consulter le [guide de depannage](watcher/docs/depannage.md) : diagnostics,
   logs et problemes courants.
3. Chercher dans les [issues existantes](https://github.com/MattiaPARRINELLO/autologin/issues)
   si la question a deja une reponse.

## Poser une question d'usage

Ouvre une [question](https://github.com/MattiaPARRINELLO/autologin/issues/new?template=question.yml).
Le formulaire demande le composant concerne, la plateforme et la version, ce qui
accelere le diagnostic. Les Discussions GitHub ne sont pas activees, la question
reste donc une issue publique qui peut etre fermee une fois resolue.

## Signaler un bug ou proposer une fonctionnalite

- Bug : [formulaire de bug](https://github.com/MattiaPARRINELLO/autologin/issues/new?template=bug_report.yml)
- Fonctionnalite : [formulaire de fonctionnalite](https://github.com/MattiaPARRINELLO/autologin/issues/new?template=feature_request.yml)

Ne joins jamais de mot de passe, de jeton ou de capture contenant des donnees
personnelles.

## Signaler une faille de securite

Utilise la [politique de securite](SECURITY.md), jamais une issue publique.

## Versions et historique

Les notes de release GitHub sont l'historique officiel du projet : chaque
version stable et beta y est decrite. Il n'y a pas de `CHANGELOG.md` separe,
cette decision est documentee dans [CONTRIBUTING.md](CONTRIBUTING.md).
