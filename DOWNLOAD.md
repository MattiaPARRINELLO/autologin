# Download CheckMate

CheckMate is a local desktop app for students using CESAR Emineo. It watches
your class windows, detects when a teacher opens attendance, and signs after
your confirmation.

## Closed beta

The desktop beta is closed and invite-only. Public downloads will open after
code signing is in place. To request access, open an issue on the repository.
If you are a beta tester, use the private beta repository link you received.

## Windows

- Windows 10 or 11
- Microsoft Edge or Google Chrome
- Installer: `CheckMate-Setup-0.1.1.exe`
- Run it, then follow the onboarding

## Linux

- systemd
- [uv](https://docs.astral.sh/uv/)
- Archive: `CheckMate-linux-0.1.1.tar.gz`
- Extract it and run `./install.sh`

## Code signing

Windows builds are code-signed by the
[SignPath Foundation](https://signpath.org/). The current beta build is
unsigned while the signing setup is pending.
