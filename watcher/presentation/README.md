# Présentation

`index.html` est un deck autonome, sans build : ouvre-le dans un navigateur.

- Fleches, espace, Page suivante : navigation
- Molette et swipe : navigation
- Pastilles a droite : acces direct a une diapositive
- Home / End : premiere ou derniere diapositive

Les captures viennent de l'onboarding et sont dans `assets/`.
